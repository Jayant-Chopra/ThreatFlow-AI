# ThreatFlow AI

ThreatFlow AI is a vulnerability analysis and attack-path platform for JavaScript/Node.js projects.

## Repository layout

- backend/: Express API, upload flow, Prisma schema, scan orchestration
- analyzer/: AST-based security analysis engine
- graph-engine/: attack graph, risk scoring, and chokepoint logic
- fixtures/: analyzer contract examples and expected output fixtures
- docs/: project documentation and integration notes


For analyzer or graph work, use the respective directories in this repo.
